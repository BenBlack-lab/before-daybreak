# Before Daybreak

A short branching story about promises, evidence, and who gets out. Built with Next.js and Sanity for the DEV Sanity Challenge, Path Two.

## Source

Download [before-daybreak-source.zip](before-daybreak-source.zip) and extract it. This archive contains the complete project with its original folder structure: application, schemas, story documents, tests, build scripts and lockfile. It contains no credentials or private engine files.

Inside the extracted folder:

```sh
npm ci
npm test
npm run build:next
npm start
```

Open http://127.0.0.1:3210. See the README inside the archive for authoring and hosting instructions.

Sanity project: `o1wtlllc`; public dataset: `production`; episode: `bd-episode`.

Three decisions create ten complete decision sequences, combining five material people-outcomes and different evidence, promise and responsibility consequences. No player account or paid AI service is required.

This repository distributes the source as an archive; extract it before running the app.
